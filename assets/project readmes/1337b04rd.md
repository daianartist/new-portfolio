> An anonymous imageboard built in Go. You get a Rick & Morty character. You post. You disappear.

---

## What is this?

1337b04rd is a simplified imageboard — think early internet forums where anyone could post anything without signing up. On your first visit, the server assigns you a random character from the Rick & Morty universe as your anonymous identity. Your posts and comments carry that avatar, but nobody knows who you really are.

Threads expire automatically:
- **No replies?** Gone in 10 minutes
- **Has replies?** Gone 15 minutes after the last one

Expired threads don't disappear — they move to the archive where they can be read but not replied to.

## Architecture

This project strictly follows **Hexagonal Architecture**. The domain layer has zero dependencies on infrastructure — it only talks through interfaces.

```
┌──────────────────────────────────────────────────┐
│                  HTTP Layer                       │
│         handlers.go  ·  middleware.go             │
└─────────────────────┬────────────────────────────┘
                      │ calls ports (interfaces)
┌─────────────────────▼────────────────────────────┐
│               Service Layer                       │
│  CreatePost · CreateComment · GetOrCreateSession  │
│  StartCleanupWorker · archiveExpiredPosts         │
└─────────────────────┬────────────────────────────┘
                      │ implemented by
┌─────────────────────▼────────────────────────────┐
│                 Adapters                          │
│  postgres/  ·  s3/  ·  rickmorty/                │
└──────────────────────────────────────────────────┘
```

**Rule:** `service/` never imports `postgres/`, `s3/`, or `net/http`. It only imports `ports/` interfaces — making it fully testable with mocks.

## Quick Start

### 1. Clone

```bash
git clone <your-repo-url>
cd 1337b04rd
```

### 2. Start services

```bash
# PostgreSQL
docker run -d \
  --name 1337b04rd-postgres \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=secret \
  -e POSTGRES_DB=board \
  -p 5433:5432 \
  postgres:16

# MinIO
docker run -d \
  --name 1337b04rd-minio \
  -e MINIO_ROOT_USER=minioadmin \
  -e MINIO_ROOT_PASSWORD=minioadmin \
  -p 9000:9000 \
  -p 9001:9001 \
  minio/minio server /data --console-address ":9001"

# Make buckets public (required for images to display)
docker exec 1337b04rd-minio sh -c \
  "mc alias set local http://localhost:9000 minioadmin minioadmin && \
   mc anonymous set public local/posts && \
   mc anonymous set public local/comments"
```

### 3. Build & run

```bash
go build -o 1337b04rd ./cmd/1337b04rd
./1337b04rd --port 8080
```

Open **http://localhost:8080**

## Key Implementation Details

**Image validation** — uploads are validated using magic bytes (not just Content-Type headers), supporting JPEG, PNG, GIF, and WebP.

**Avatar uniqueness** — avatar index is assigned sequentially based on total session count, ensuring each new user gets a different Rick & Morty character. Wraps around after all 826 characters are used.

**Auto-archiving** — a background goroutine ticks every minute and archives posts that have exceeded their time limit. Uses `time.Ticker` for concurrency.

**S3 without SDK** — MinIO is called via raw HTTP with AWS Signature V4 signing implemented from scratch using only the standard library, as external packages (except the PostgreSQL driver) are not allowed.

**Graceful shutdown** — the server listens for `SIGINT`/`SIGTERM` and gives active connections 10 seconds to finish before shutting down.
